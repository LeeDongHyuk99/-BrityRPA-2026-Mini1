# Brity RPA 2026 미니프로젝트 1

## 📌 프로젝트 개요
본 프로젝트는 **Brity RPA**를 활용하여 업무 자동화를 구현한 미니프로젝트입니다.  
이미지 분석 및 생성, 그리고 RPA 기반 데이터 처리 흐름을 중심으로 구성되어 있습니다.

---

## 🛠 사용 기술
- **Brity RPA**
- RPA Execute Script
- 업무 자동화 시나리오 설계

---

## 📂 프로젝트 구성

Brity RPA-mini1/

└─ README.md

---

## 🧩 주요 기능
- 이미지 분석 자동화
- 분석 결과 기반 이미지 생성 프로세스
- RPA 시나리오 흐름 설계 및 실행

---

## ▶ 실행 방법
1. Brity RPA Studio 실행
2. `이미지분석및생성.ipa` 파일 Import
3. 시나리오 열기 후 실행
